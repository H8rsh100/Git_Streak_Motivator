# cursed calculator

a calculator that is slightly, deliberately, confidently wrong.

it looks normal. it acts normal. it is not normal.

---

## what's cursed about it

- `2 + 2` = `4.0000001`
- `1 + 1` = `3`
- `3 × 3` = `8`
- `7 + 7` = `13`
- `5 × 5` = `24`
- 16 other hardcoded classic equations — all wrong
- 35% chance of a tiny floating point nudge on *any other* calculation
- every wrong answer comes with a certification message like `"trust me bro"` or `"peer reviewed"`

## usage

just open `index.html` in a browser. no build step. no dependencies. no npm install. just vibes.

```bash
open index.html
# or
python3 -m http.server 8080
```

keyboard support works too: numbers, operators, Enter, Escape, Backspace.

## the philosophy

calculators are supposed to be trustworthy. this one looks trustworthy. it has the same buttons. the same layout. the same confident beep-boop energy.

it just occasionally lies to you.

this is a metaphor. for something. i'm not sure what.
